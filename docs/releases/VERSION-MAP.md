## 对已有用户的影响

- 旧 Release 链接（如 `/releases/tag/v2.4.0`）会 404，GitHub 不提供 Release 重定向。
- 已 fork 的仓库不受影响；执行 `git fetch --tags` 不会删除本地旧标签，可手动 `git tag -d v2.0.0 …`。
- 外部 CI 若引用 `v3.0.0`，请改用 `v1.6.0`；需要旧提交时使用 `archive/v3.0.0`。
- `git describe` 在新克隆中返回 `v1.6.0`；旧克隆可能仍显示旧标签，属预期。
