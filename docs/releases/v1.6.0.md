# IT Toolbox v1.6.0

**发布日期**：2026-11-04

首个采用连续 `v1.x` 版本序列的正式版本。在保留 144 个可用工具的前提下，完成缺陷修复、性能优化、测试与工程门禁建设。

## 概览

- 工具：144 个（下线无后端支撑的 Webhook 测试，净减 1）
- 首屏体积：321 KB → **169 KB**（gzip）
- Service Worker 预缓存：187 条 / 7.9 MB → **18 条 / 1.5 MB**
- 测试：0 → **331 条**，core 行覆盖 91.5%
- 质量门禁：lint **0 error / 0 warning**，CI 串 typecheck → lint → test → build

## 版本号方案调整

旧的 `v1.0.0 / v2.x / v3.0.0` 已收敛为 `v1.0.0 → v1.6.0`，历史标签以 `archive/*` 保留。详见 [VERSION-MAP.md](./VERSION-MAP.md)。

## 修复

### P0（功能不可用 / 假数据）

- AI 报错解释：请求字段与后端不一致，此前每次必然 400
- JSON-RPC 测试：按代理真实响应信封解析，成功路径恢复可用
- Webhook 测试：依赖的路由从未实现，本版本下线
- WHOIS：改用 RDAP 查询真实注册商/注册与到期时间/NS/状态；IP 输入走归属地模式
- AI 正则：非法 pattern 不再导致渲染崩溃，移除 `dangerouslySetInnerHTML`

### P1（正确性 / 安全）

- Markdown 渲染改为 DOM 白名单净化（标签/属性/协议）
- 代理增加 SSRF 防护：内网/回环/云元数据地址拦截、最多 2 跳重定向、2 MB 上限
- headers-check 不再破坏 URL 路径与查询参数大小写
- SSL 检测删除硬编码签名算法，不再把「可连通」判定为证书有效
- 时区换算按源时区墙上时间计算，支持夏令时
- 罗马数字支持 IV/IX/XL/XC/CD/CM 并拒绝非标准写法
- 工具对比的伪 MD5 替换为真实 MD5
- 12 个 AI 工具统一超时、非 JSON 响应与 HTTP 错误处理
- 修复 26 个非法图标名、19 个 meta/registry 名称不一致、4 个缺失 API 标记

## 性能

- 图标改为 86 个显式映射，移除 `import * as lucide-react`
- 页面级路由懒加载；工具 chunk 输出为 `dist/tools/<id>-<hash>.js`
- core 拆分 `format-yaml / text-diff / text-cron / generator-fake / network-ua`，49 个文件改为子路径导入
- Service Worker 只预缓存应用壳，工具 chunk 首次访问后按需缓存
- 新增 `vite:preloadError` 自动刷新兜底

## 工程质量

- 接入 Vitest + happy-dom：core 105 函数表驱动测试、Hono 路由契约测试、元数据一致性测试
- 新增 CI、元数据审计、图标同步检查、整店订阅检查、体积报告脚本
- 状态层改为字段级订阅（77 个文件），persist 增加版本迁移、写入节流与容量上限
- 历史记录仅对 19 个非敏感工具开启，HistoryPage 支持查看/复制/删除

## 破坏性变更

- 旧 Release 标签 `v2.x` / `v3.0.0` 删除，链接会 404
- `localStorage` 存储结构升级到 version 1，首次加载自动迁移
- Service Worker 策略变更，首次访问新版本后会自动接管缓存

## 已知限制

- `whois` 依赖 `rdap.org` 可用性，部分小众后缀可能无 RDAP 记录
- `ssl-check` 依赖 crt.sh 数据，取不到证书详情时只显示连接状态，不再推断有效性
- AI 工具依赖 Cloudflare Workers AI 绑定，本地开发需配置 `[ai]` binding
